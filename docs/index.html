Sensor-oriented image processing & CNN denoising

End-to-end Python pipeline: classical ISP-style algorithms, synthetic noise, residual CNN, PSNR / SSIM.

GitHub repository Profile (@EDENMALKA123) LinkedIn

Overview

This project targets roles that combine image processing, computer vision, and deep learning (for example mobile or automotive image sensors and ISP-style tuning). It implements a full loop from data preparation through classical preprocessing and a trained convolutional denoiser, with quantitative metrics.

STL-10 → grayscale patches → augmentation → Gaussian noise → CNN predicts noise → PSNR / SSIM

Algorithms covered

AreaImplementation
Convolution & smoothingGaussian blur, median, bilateral (src/classical.py)
EdgesSobel, Canny
ThresholdingGlobal, adaptive, Otsu
ContrastHistogram equalization
Geometry / regionsMorphology, connected components, Hough (probabilistic lines)
ResamplingNearest / bilinear / bicubic resize
Deep learningCNN + BatchNorm + ReLU; residual noise prediction; training loop (src/models.py, src/train.py)
DataPatch dataset, flips/rotations/crops, random noise level (src/dataset.py)

Quick start

Environment

python -m venv .venv
source .venv/bin/activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt

Data & train

python scripts/prepare_data.py --root ./data
python -m src.train --data-root ./data --epochs 5 --batch-size 16 --out-dir ./outputs

Compare classical vs CNN

python -m src.demo --data-root ./data --weights ./outputs/weights.pt

No PyTorch (classical demo only)

pip install numpy opencv-python-headless scikit-image scipy matplotlib
python scripts/classical_skimage_demo.py
